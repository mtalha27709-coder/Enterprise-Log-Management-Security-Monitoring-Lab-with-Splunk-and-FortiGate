# SOC Home Lab: Splunk SIEM for Security Monitoring & Threat Detection

## 📌 Overview

This project demonstrates the design and deployment of a SOC-focused Security Information and Event Management (SIEM) home lab using Splunk Enterprise.

The goal of this lab was to simulate real-world SOC (Security Operations Center) environments and gain hands-on experience in log management, security monitoring, threat detection, incident investigation, and threat hunting.

Multiple log sources were integrated into Splunk to build a centralized security monitoring system capable of analyzing and visualizing security events in real time.

---

## 🎯 Objectives

- Build a complete SIEM environment from scratch
- Simulate real-world SOC analyst workflows
- Centralize and analyze logs from multiple sources
- Perform threat hunting using SPL queries
- Detect and investigate security incidents
- Develop security dashboards and reports
- Improve troubleshooting and analytical skills

---

## 🏗️ Lab Architecture

### 🔧 Components Used

- Splunk Enterprise (SIEM Platform)
- Apache Web Server (Web Logs Source)
- FortiGate Firewall (Syslog Source)
- Linux Environment (System & Log Management)

### 🔄 Data Flow

Logs are generated from multiple sources → forwarded to Splunk → indexed & parsed → analyzed using SPL → visualized in dashboards for monitoring & investigation.
